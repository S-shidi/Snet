<!-- release-notes-v1.2.5 -->

## v1.2.5

### 客户端

- 创建者视角设备卡片新增“节点 ID”，与“设备 ID”一样支持点击复制。
- 新建/编辑网络虚拟网段改为 5 格输入：首段为 `10/172/192` 下拉，末段为私有网段前缀下拉，
  `.` 与 `/` 始终显示在输入格外。设置页支持“保持当前网段不变”。
- “更多”菜单新增“移交网络”；修复点击确认后无响应：补齐 `/ctl/role` 调用链，
  去除会覆盖原弹窗的嵌套确认，并在移交成功后立即更新本机创建者标记。
- 服务端删除或移除已加入网络后，客户端状态返回 `notice`，UI 提示并从本机清除该网络。
- 主动连接与已连接网络网段冲突的网络时先确认，确认后断开冲突网络再连接。
- 关于页文案更新为：Snet构建独属于你的私域网络，无论身在何处，轻松直连你的家庭与公司网络，
  让你的网络更安全更隐私。
- Android `versionCode` 升至 14。

### 服务端（`server/v1.2.5`）

- 显式虚拟网段允许重复/重叠（自动分配仍避开已用网段）。
- 新增持久化操作日志：创建、加入、待审批、退出、踢出、角色调整/移交、删除及管理员操作；
  后台网络详情可查看最近 50 条。
- 管理端网络详情新增“操作日志”区域。

### 产物

- 客户端 `v1.2.5`：Android APK、macOS、Windows、玩客云固件、容器镜像。
- 服务端 `server/v1.2.5`：`snet-snetserv`、`snet-admin-server`、`snet-relay` 镜像与二进制包。
