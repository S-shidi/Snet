## v1.2.7

### 客户端

- 更新区域：「立即升级」与「检查更新」按钮尺寸一致；仅在检查到新版本时显示升级按钮，
  已是最新版本时只保留「检查更新」。
- 诊断日志导出：macOS / Windows 客户端直接写入 `~/Downloads/snet-diagnostic-<时间>.log`
  并提示完整路径；Web 提示浏览器下载目录，Android 保持系统分享面板。
- 成员设备卡片：设备 ID / 节点 ID 在窄屏保持单行，超出省略，仍可点击复制。
- 网络详情标题栏：「邀请」「更多」补充文字标签，更多菜单改为竖排三点图标。
- 移动端顶栏：刷新、设置保持常驻，不再收进「更多」，与 Web 一致。
- 创建网络限制对齐服务端：一设备一自有网络按 SnetServ 计算，允许在更换协调服务后创建；
  守护进程不再把已确认删除的旧网络计入限制。
- 修复桌面端（macOS / Windows）一键升级确认后设置面板被关闭、进度与状态不可见的问题：
  点击「立即升级」直接开始，在设置面板内显示下载、校验、安装与重启进度，失败时弹出错误提示。

### 配合服务端

- 服务端 `server/v1.2.7` 在移交网络时校验目标设备是否已有网络，拒绝时返回明确提示。
- Android `versionCode` 升至 16。

### 产物

- 客户端 `v1.2.7`：Android APK、macOS DMG、Windows 安装器/压缩包、玩客云线刷固件、
  全平台二进制包、GHCR/ACR 容器镜像（`v1.2.7` / `latest`）。
